# Mind Map Study App

Tree-first MERN starter for a vertical mind map and revision tool.

## Stack

- Frontend: React + Vite + Zustand + React Query
- Backend: Node.js + Express + Mongoose
- Database: MongoDB

## MVP features included

- Create or load a single nested mind map
- Render a vertical connected tree
- Select a node to view and edit details
- Add child nodes
- Whole-map save flow
- Step Mode with depth-based reveal
- Search and active path highlighting

## Project structure

- `frontend/` React client
- `backend/` Express API

## Next steps

1. Install dependencies in `frontend/` and `backend/`
2. Add a `.env` file in `backend/`
3. Run MongoDB locally or point `MONGODB_URI` to Atlas
4. Start backend, then frontend
